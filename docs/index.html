Very Goods bookmarklet

An unofficial rebuild of the verygoods.co "save a product" bookmarklet. The original stopped working when browsers began blocking third-party cookies. This one should work more reliably with modern browsers.

Drag this to your bookmarks bar:

Very Goods

Then, on any product page: scroll the photos into view, click the bookmark, and pick an image in the popup. If the popup comes up empty, click the bookmark again — it re-sends to the open popup. You need to be signed in at verygoods.co in the same browser.

If a page shows no photos, this one lists what the bookmarklet can see there:
